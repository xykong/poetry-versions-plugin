Hi! Thank you for asking about Poetry version compatibility.

## Current Status ✅

I'm happy to confirm that **this plugin now supports both Poetry 1.x and 2.x**:

- **Poetry 1.2+** (tested with 1.2.0 through 1.8.x)
- **Poetry 2.0+** (tested with 2.0.0 through 2.1.x)

## What Changed

I've just implemented full backward compatibility support. The plugin now:

1. **Automatically detects** which Poetry version you're using
2. **Supports PEP 621** format (`[project].version`) for Poetry 2.x projects
3. **Maintains compatibility** with traditional `[tool.poetry].version` format
4. **Prioritizes correctly** when both formats exist (PEP 621 takes precedence)

## Installation

Simply install with:

```bash
poetry add poetry-versions-plugin
```

The plugin will work seamlessly regardless of whether you're using Poetry 1.x or 2.x.

## Technical Details

The compatibility layer:
- Checks for version in `[project].version` first (Poetry 2.x PEP 621 format)
- Falls back to `[tool.poetry].version` (traditional format)
- Raises a clear error if version cannot be found

All changes are fully tested with 8 new compatibility test cases covering both version formats.
